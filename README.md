RESUMO DOS APRENDIZADOS EM PHP

Nesta revisão, aprendi a:

- Diferenciar == e ===: == compara apenas o valor, enquanto === compara o valor e o tipo.
- Usar o laço for para repetir ações e contar elementos, como os múltiplos de um número.
- Criar funções com parâmetros e retorno, incluindo validação de valores inválidos.
- Usar switch, case, break e default para escolher ações conforme uma opção informada.
- Trabalhar com arrays associativos e ordenar registros com usort, mantendo os dados relacionados.
- Percorrer arrays com foreach e ignorar itens específicos usando continue.
- Ler parâmetros enviados pela URL por meio da superglobal $_GET, que armazena dados em um array associativo.
- Criar classes, propriedades, métodos, construtores e objetos em PHP.
- Compreender herança e visibilidade: public pode ser acessado livremente, protected pelas classes filhas e private somente pela própria classe.
- Criar uma autenticação simples usando classe, sessão e cookie. A sessão mantém dados do usuário no servidor durante a navegação, enquanto o cookie armazena informações no navegador por um período definido.

Esses exercícios ajudaram a praticar lógica de programação, organização de dados e conceitos básicos de programação orientada a objetos no desenvolvimento back-end com PHP.
